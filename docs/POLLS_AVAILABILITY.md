# 民調彙整（公開可得性說明）

撰寫日期：2026-10-29（UTC+8）

## 結論（鄉鎮／縣市選舉前民調）

**沒有**找到可自由下載、覆蓋全國鄉鎮、且對齊 2016／2020／2024 總統／立委的官方或學術「鄉鎮民調面板」。

縣市級商業／媒體民調存在，但多為：
- 單次新聞稿 PDF／圖表，非機器可讀長期面板；
- 抽樣設計與問題不一，難以直接併入生態迴歸；
- 投票日前十日依法限制公布（選罷法相關規範）。

因此本專案 **poll_index 特徵維持缺值**，不捏造。
