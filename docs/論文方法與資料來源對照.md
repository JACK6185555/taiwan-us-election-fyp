# 論文方法與資料來源對照（文獻做法 × 本專案）

更新：2026-10-30（Asia/Hong_Kong）

本文件係論文／附錄用對照表：整理**其他論文**如何分析選舉（問題類型、分析單位、方法做法、資料來源），並標明**本 FYP 已對應／部分對應／無法對應**之處——尤其當 TEDS、ESC 官方 Excel、鄉鎮／縣市歷史民調未能申請取得時。  
路線設計見 `docs/文獻脈絡路線.md`；申請唔到時可貼段落見 `docs/申請資料未取得時之報告說明.md`。  
**權重／MAE = 模型依賴或樣本外誤差，≠ 因果。** 本頁**不發明**新 MAE；數字只引用本專案已定稿結果。

## 1. 預測 vs 解釋（先分線再對文獻）

| 維度 | 預測／預報學（Forecasting） | 解釋／行為研究（Explanation） |
|------|------------------------------|-------------------------------|
| 核心問題 | 下一屆得票／勝選機率／區間有多準？ | 邊啲因素解釋點解人投邊邊？ |
| 典型單位 | 州／縣／全國時序；生態或彙總 | 個人調查；或多層（個人＋脈絡） |
| 成功標準 | 樣本外誤差、校準、即時更新 | 係數方向、機制、理論貢獻 |
| 常用資料 | 歷史票、基本面、民調、市場、ACS／社經 | TEDS／ANES、身份、統獨、黨性、候選人評價 |
| 本專案 | **主線**：家族 A OOT MAE；Prev **0.0793** | **對照線**：文獻章＋全國 ESC PROXY；個人係數要 TEDS |

兩條線可以並存於報告，**唔好用生態 Ridge 係數「複製」TEDS mixed logit／統獨勝算比**。
