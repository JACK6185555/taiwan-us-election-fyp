# 文獻脈絡路線：預測線 × 解釋線

更新：2026-10-30（Asia/Hong_Kong）

本文件把「點解歷史得票最好」同「跟文獻可以點寫、點做」寫清楚，方便老師報告同口試。  
**論文級「方法／做法／資料來源」逐篇對照表**見 **`docs/論文方法與資料來源對照.md`**（Linzer、Economist／Gelman、Time-for-Change、縣級 ML、TEDS／多層／MRP 等；含「本專案對應」同「申請唔到時」欄）。  
**權重／MAE = 模型依賴或樣本外誤差，≠ 因果。**

---

## 1. 點解 PreviousShare 贏？（慣性／短 T／生態）

| 機制 | 本專案現實 |
|------|------------|
| **地理黨派慣性** | 縣市／鄉鎮連幾屆 DPP／KMT 結構好穩定；上屆份額本身係極強預測 |
| **短時間序列** | 核心設定 只有少數選舉年（測試 2012／2016／2020／2024）；參數多嘅 ML 易過擬合 |
| **生態單位** | 開票係區域加總，唔係個人；社經／認同喺縣市層變動慢，資訊多被「上屆票」吸收 |
| **全國氣候衝擊** | 三腳督、重大事件改嘅係全國水平；純橫截面社經難捉「下一腳氣候」 |

因此：**預測線上 PreviousShare（核心設定 平均 OOT MAE 0.0793）贏過 Ridge／RF／HGB**，唔代表「其他文獻變數無用」，而係喺呢個單位／樣本下，**滯後得票已經係夠強嘅先驗**。

特徵權重見 `docs/特徵權重說明.md`：Ridge／RF 幾乎由 `prev_*`／`prev2_*` 主導；A+ 加滯後失業／所得／密度＋ESC PROXY 後 Ridge MAE 0.179→**0.143**，仍贏唔過 Prev。

## 2. 兩條線（唔好混報）

### 預測線（Prediction track）— 主數字

- **目標**：時間外推（OOT）下嘅得票份額／swing／demeaned  
- **評分**：MAE／RMSE；核心設定 為**唯一主結果**（`docs/SUBMISSION_AUDIT.md`）  
- **做法**：歷史票作基準／先驗；可加滯後基本面（失業、所得、密度）；可選全國態度 PROXY（ESC 公開轉錄）；理論上可加民調更新（Linzer 式）——**鄉鎮／縣市歷史民調面板公開上唔齊，見 `docs/POLLS_AVAILABILITY.md`**  
- **可講**：邊個模型 OOT 較準；邊啲特徵模型依賴高  
- **唔好講**：政策／失業率「導致」勝選；勝選機率產品

### 解釋線（Explanation track）— 文獻機制

- **目標**：對照臺灣／比較政治文獻：身份、統獨、黨性、地方脈絡點解釋投票  
- **單位**：理想係**個人**（TEDS）或多層（個人＋鄉鎮脈絡）；本專案主資料係**生態**  
- **可講**：文獻機制排序；全國 ESC PROXY 同全國氣候並讀；為何生態權重≠個人因果  
- **唔好講**：用鄉鎮 MAE 或 Ridge 係數「複製」TEDS mixed logit／統獨勝算比

兩條線可以並存於報告：**預測誠實承認歷史基準；解釋章節跟文獻講身份／統獨／脈絡，並標明缺微資料時嘅限制。**

## 3. 文獻錨點（真實來源＋連結）

### 預測／預報學

| 來源 | 重點 | 本專案用法 |
|------|------|------------|
| [Linzer (2013) JASA](https://doi.org/10.1080/01621459.2012.737735) | 動態貝葉斯：早期靠歷史／基本面，近投票日跟州級民調 | 預測線理想型；缺縣市民調面板 → 只能做到「歷史＋滯後社經＋全國 PROXY」 |
| [Abramowitz Time-for-Change](https://centerforpolitics.org/crystalball/time-for-change-model-predicts-close-election-with-slight-edge-for-kamala-harris/) | 總統支持度、經濟、執政年期 → 全國／州級 | 縣市細節解唔開；經濟須用**即時／滯後**，唔用事後修正當因果 |
| [Leigh & Wolfers NBER w12053](https://doi.org/10.3386/w12053) | 預測市場 vs 民調 | 臺灣無穩定公開縣市博彩面板；本專案未入模 |
| [Brito et al. 社群媒體回顧](https://doi.org/10.1109/tcss.2021.3063660) | 單靠社群情緒／量多數唔贏隨機 | 未入主模型；只作文獻 caution |

### 臺灣解釋線（身份／統獨／脈絡）

| 來源 | 重點 | 本專案用法 |
|------|------|------------|
| [Political Science 2019 ethnoterritorial ideology](https://doi.org/10.1080/00323187.2019.1601021)（DOI `10.1080/00323187.2019.1601021`） | 國族／族群領土意識形態同投票 | 解釋線主軸；**需個人態度** → 理想 TEDS／ESC；現用全國 ESC PROXY 只當氣候 |
| 地方脈絡／生態研究（例：[Airiti 地方脈絡文](https://airitilibrary.com/Publication/alDetailedMesh?DocID=10132511-201106-201109230004-201109230004-119-149)） | 同樣教育／收入喺唔同鄉鎮投唔同 | 對應同縣空間滯後／縣平均；**生態相關 ≠ 個人因果** |
| MRP 小區推估（例：[政大／相關方法文 PDF](https://scups.ppo.scu.edu.tw/upload/f20220531115044t477m1.pdf)） | 全國調查 → 選區／立委 | 單位唔同，唔好同鄉鎮 MAE 直接比；指出「有 TEDS 先可以 MRP」 |
| ESC 趨勢圖（政大選研） | 認同／統獨／政黨偏好全國趨勢 | 已用公開轉錄 PROXY：`data/esc_proxies/`；完整 Excel 需申請（`docs/ESC_SOURCES_AND_ACCESS.md`） |
| TEDS | 黨性、統獨、候選人評價、獨立選民 | **未取得微資料**；步驟見 `docs/TEDS_ACCESS.md`；報告用語見 `docs/申請資料未取得時之報告說明.md` |

美國對照（補充）：縣級亦係歷史票主導（`results/feature_weights/`）；同「慣性」敘事一致。

更完整嘅「文獻方法 × 資料來源 × 本專案可否對應」主表：`docs/論文方法與資料來源對照.md`。

### 要申請／額外工作先做得到（解釋線升級）

1. **TEDS 微資料** → 個人黨性／統獨／候選人評價；可做解釋模型或 MRP  
2. **ESC 官方趨勢 Excel** → 密政黨偏好全國序列  
3. **縣市／鄉鎮歷史民調面板**（人工彙整或商業庫；遵守選罷法公布限制）→ Linzer 式更新  
4. **縣市族群／籍貫**（客家調查縣市表、戶政原住民等）→ 核對授權與 join 後再作結構 PROXY（仍非個人身份）
