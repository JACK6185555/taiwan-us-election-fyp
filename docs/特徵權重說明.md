# 特徵權重說明（臺灣縣市總統票｜Family A／A+｜美國對照）

更新：2026-10-30 14:24 Asia/Hong_Kong (UTC+8)

## 必讀：權重唔係因果、唔係勝選原因

本文件嘅「權重／重要性」只描述模型喺**整屆留出（out-of-time）**回測入面**點樣依賴特徵**。

- **唔係**因果效應（唔代表改呢個變數就會改得票）
- **唔係**選情斷言或勝選原因
- Ridge 係**標準化後有號係數**（跨 OOT fold **平均**，唔係只取最後一屆）
- RF／HGB 係**置換重要性**（打亂特徵後 OOT MAE 升幾多）同 impurity（RF）
- 只有四個測試屆（2012／2016／2020／2024），排名會有波動
