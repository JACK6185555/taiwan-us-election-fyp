# 縣市民調缺口說明（Extension vs Family A）

**日期：** 2026-10-30（Asia/Hong_Kong, UTC+8）

## 結論

本專案交付包內之選前民調長表（`data/extension_poll_platform/taiwan_polls*.csv`）之 `region` 欄經核對為 **全部 `national`（5165／5165 列）**。  
**沒有**可自由下載、機器可讀、覆蓋 2012–2024 總統選前、且對齊縣市／鄉鎮單位的公開歷史民調面板。

因此：

1. **Family A** 主表**不**納入 poll 特徵；定稿仍以 PreviousShare **0.0793** 等歷史／社經線為準。  
2. **UniformPollSwing／History+Poll** 僅屬 **Extension**（`results/extension_poll_platform/`）：全國同一 poll swing 廣播到所有縣市——測試「全國氣候刻度」而非「縣市標籤準確率」。  
3. 勿把 Extension 低 MAE（如 UniformPollSwing **0.0266**）與家族 A 混報或當產品預測。

## 點解公開管道搵唔到縣市面板

- 媒體／民調機構多以**全國**或單次新聞稿／圖表發布縣市數字，缺統一 CSV 與跨屆題幹。  
- 選前十日依法限制公布；歷史檔零散。  
- 學術個體意向在 **TEDS**（需申請）；ESC 公開趨勢亦係**全國**態度，非縣市選前支持度面板。  
- gohomi 等公開 API 多為**地方選**近況，唔適用 2016–2024 總統縣市 OOT。

詳見 `docs/POLLS_AVAILABILITY.md`、`docs/申請資料未取得時之報告說明.md`。

## 若日後要補

人工彙整媒體縣市民調（標機構／日期／題幹／n）或申請調查微資料後，另表做 expanding-window 更新；**不**覆蓋家族 A 主數字。
