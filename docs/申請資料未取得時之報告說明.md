## B. 預測線：可以主張什麼、不可以主張什麼

**可以主張**

1. 在嚴格時間外推（訓練年嚴格早於測試年；測試屆 2012／2016／2020／2024）下，縣市層級民進黨總統有效票份額的**歷史方法比較**結果（家族 A）：Previous-election baseline 平均 MAE **0.0793**，優於本專案所擬合之 Ridge／Random Forest／HistGradientBoosting。  
2. 加入公開滯後社經與全國 ESC PROXY（Family A+）後，線性模型誤差可改善（Ridge 約 0.179→**0.143**），但**仍未穩勝** PreviousShare；故不宣稱「社經已擊敗歷史基準」。  
3. 特徵 permutation／Ridge 係數所反映者為 **out-of-time 模型依賴（model dependence）**，用於說明擬合幾乎跟隨上屆（與前兩屆）政黨結構。

**不可以主張**

1. 不發布勝選機率或未來選舉準確率保證。  
2. 不把生態迴歸係數或 impurity 解釋為失業率、所得或某政策的**因果效應**。  
3. 在欠缺縣市／鄉鎮歷史民調面板時，不宣稱已實施 Linzer（2013）式「民調動態更新」預報系統。  
4. 全國 ESC PROXY 只代表公開可得之**全國氣候刻度**，不能替代縣市異質態度，亦不能替代官方 Excel 之完整政黨偏好序列。

## C. 解釋線：缺 TEDS／完整 ESC 時如何寫

臺灣政治學文獻指出，**國族認同、統獨立場、政黨認同與地方脈絡**是解釋個人投票的核心機制（例如 ethnoterritorial ideology 相關研究，DOI [10.1080/00323187.2019.1601021](https://doi.org/10.1080/00323187.2019.1601021)；以及地方脈絡／生態與 MRP 小區推估傳統）。  
在未能取得 TEDS 微資料之前，本專案**無法**：

- 估計個人層「統獨升一級 → 投泛藍勝算變化」等文獻係數；  
- 區分純獨立選民與 leaners 的候選人評價效應；  
- 以 MRP 將全國調查可靠下推至選區／鄉鎮並與開票對校。

因此解釋章節採**文獻機制整理＋全國 PROXY／生態結果對照**：說明「為何預測被歷史票主導」與「文獻認為個人層真正重要的變數是什麼」可以並讀，但**兩者單位不同，不可互相替代因果宣稱**。香港因素、政綱口號、中間選民等章節同樣只作公開敘事或內容編碼，**不新造**個體係數。
