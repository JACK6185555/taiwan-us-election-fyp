## 重要聲明

- **官方趨勢 Excel 不公開直連**，須向 esc@nccu.edu.tw 申請簽名申請表。  
- 本目錄數值來自：**Wikimedia Commons 表格**、**Wikipedia 轉載表**、**中央社／NOWnews／VOA 等引用 ESC 的新聞**，每列有 `provenance_note`。  
- **不是** ESC 官方 Excel；用於 FYP 的全國常數 PROXY 時須在報告標明。  
- 引用學術寫作時仍請註明：「資料來源：國立政治大學選舉研究中心重要政治態度分佈趨勢圖」，並優先改用官方 Excel。
